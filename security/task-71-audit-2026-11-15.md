## Results and triage

### Dependency and credential checks

- The secret guard passed: `.env` was ignored and untracked, and no configured
  high-signal access-key or private-key pattern was found.
- `pip-audit` reported no known vulnerability in installed third-party Python
  packages. The editable local application was skipped, as expected.
- `npm audit --omit=dev --audit-level=moderate` reported zero vulnerabilities in
  deployed frontend dependencies.
- The full npm audit reported seven moderate development-only entries in the
  `typescript-eslint`/`minimatch` lint toolchain. They are not included in the
  production Vite bundle. npm's proposed forced change is a major toolchain
  change and was not applied without a compatible reviewed upgrade.

### Open-source source-code audit

Bandit inspected 13,802 lines and reported 14 findings: 13 low severity and one
medium severity, all with high confidence. It reported no high-severity finding.

| Finding | Triage | Decision |
| --- | --- | --- |
| B310 in `commands/verify_sources.py` | The legacy developer command calls `urlopen`. Its default inventory is committed and reviewed, but `--inventory` could name a file containing a non-HTTPS or non-CMS URL. The deployed ingestion service does not use this command and independently enforces HTTPS, the CMS allowlist, redirect validation, timeouts, and size limits. | Not a deployed-path release blocker. Do not run the legacy command with an untrusted inventory; harden or retire it in maintenance. |
| B101 assertions in admin response refreshes | These assertions check service invariants after explicit not-found handling or a committed mutation. They are not authorization or publication gates. | Low risk. Replace with explicit internal errors during later error-handling cleanup. |
| B101 assertions in semantic evaluation | These follow fixture eligibility checks in the fictional evaluation harness. | Accepted as evaluation-only. |
| B404/B603 in `prepare_review_crosswalk.py` | The command invokes the resolved `pdftotext` executable with a fixed argument vector, `shell=False`, and a local reviewed path. | Accepted for the offline maintainer tool. |

## Residual actions

1. Upgrade the TypeScript/ESLint toolchain only when a compatible patched chain
   is available; do not use `npm audit fix --force` blindly.
2. Harden or remove the legacy `verify_sources` downloader before accepting
   user-supplied inventory files.
3. Replace production-path diagnostic assertions with explicit internal errors
   when those handlers are next modified.
4. Rerun `make security-audit` immediately before submission because advisory
   data changes independently of the repository.
